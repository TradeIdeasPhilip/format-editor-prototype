Known formats

One name per line. In the real program these would come from the Text Format components. Try deleting or renaming one.

Editor

  • Type normally. Enter adds a newline.
  • Copy, cut, and paste use the ⸨name⸩ text format, so you can paste to and from VS Code.
  • Unknown format names are red.
  • Undo and redo work with ⌘Z / ⇧⌘Z (or Ctrl+Z / Ctrl+Y).
